# Release Notes for v2025.9.0

## Overview
This release focuses on significantly enhancing the tent functionality, improving journal and logging capabilities, adding support for additional sensors like CO2, and improving the precision of all sensors. This is a major update that brings substantial improvements to the Brokkoli Plant Manager integration.

## What's Changed

### Enhanced Tent Functionality
- Completely redesigned tent management system with improved sensor handling
- Added TentMaintenanceSelect UI component in tent_select.py for predefined maintenance options
- Implemented TentJournal and TentMaintenance text entities in tent_text.py for free-form entries
- Added add_journal method to Tent class to support integration with the text platform
- Improved tent sensor configuration completeness including both air humidity and soil moisture sensors
- Fixed tent sensor mapping and plant assignment issues
- Enhanced tent sensor management to prevent connection issues

### Journal and Logging Improvements
- Significantly improved logging throughout the integration for better debugging
- Fixed manual watering journal entries to only record the watering amount without any preceding message
- Enhanced journal functionality with better entity setup during async_setup_entry
- Added verbose logging options for advanced troubleshooting

### Additional Sensor Support
- Added comprehensive CO2 sensor support with proper threshold management
- Implemented support for additional sensor types in tent configurations
- Enhanced sensor configuration flow to include all relevant sensor types
- Improved sensor listing service to show all available sensors

### Sensor Precision Improvements
- Enhanced precision for all sensor measurements
- Improved data processing pipeline for more accurate readings
- Added better decimal handling for different sensor types
- Implemented centralized decimal configuration management
- Enhanced sensor value rounding and formatting

### General Improvements
- Improved error handling for service calls
- Enhanced data export/import functionality with better image handling
- Fixed change tent functionality with better entity resolution
- Updated sensor management for tents to prevent connection issues
- Enhanced data export/import functionality with better image handling

## How to Update
1. Remove the existing Brokkoli Plant Manager integration from HACS
2. Add the repository again as a custom repository if needed
3. Install version 2025.9.0
4. Restart Home Assistant

## Compatibility
This version requires Home Assistant 2025.9.0 or later.
