# Changelog

## [2025.9.0] - 2025-09-29

### Added
- Enhanced tent functionality with improved sensor management
- Additional CO2 sensor support
- Improved sensor precision for all measurements
- Enhanced tent UI components including TentMaintenanceSelect and TentJournal/TentMaintenance text entities
- Better tent journal functionality with add_journal method

### Fixed
- Improved logging throughout the integration for better debugging
- Fixed tent sensor mapping and plant assignment issues
- Fixed change tent functionality with better entity resolution
- Improved error handling for service calls

### Changed
- Updated sensor management for tents to prevent connection issues
- Enhanced data export/import functionality with better image handling
- Improved tent sensor configuration completeness including humidity and moisture sensors

## [2025.4.0] - 2025-04-01

### Added
- Initial release of Brokkoli Plant Manager for Home Assistant
- Plant monitoring with configurable sensors
- Basic tent management system
- Consumption tracking for water, fertilizer, and power
- Plant lifecycle management
- Integration with OpenPlantbook for plant data
- Export/Import functionality for plant configurations
